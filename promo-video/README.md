# Boboteca / ClubPlatform — Remotion test video

Independent video project. It does not change the application build or depend on a live API while rendering.

- Output: `out/boboteca-flow.mp4`
- 58 seconds, 1080 × 1920 vertical, 30 fps, H.264.
- Spanish captions; original locally synthesized instrumental soundtrack, no voiceover.
- Illustrated product UI with staged data, not a recording of a customer's purchase.
- Contact number masked. QR-like graphics are marked DEMO and carry no ticket credentials.
- Security and bar are explicitly labeled as future F5 previews. Cashier sales are accurately labeled Demo-only. No admission or redemption is presented as implemented.

## Run

From this folder:

```powershell
npm ci
node scripts/audio.mjs
npm run studio
```

Preview in Remotion Studio, then render:

```powershell
npm run check
npm run render
npm run still
```

The scene list and animation are in `src/index.tsx`. Change the `scenes` timing/text and the corresponding `Panel` to edit the film. Rendered frames use deterministic frame-based animation. All Remotion packages are pinned to the same version in package.json and package-lock.json.

The music is generated by `scripts/audio.mjs`; no stock music or external media services are used. No messages are sent to WhatsApp by the video or its scripts.

## Verification

Rendered with Remotion 4.0.543. TypeScript check passes; npm audit reports zero known vulnerabilities at creation time. Ten storyboard frames were rendered and visually reviewed. The MP4 is checked in Chromium for metadata, seeking/decoding at seven points and audible, unclipped audio. `out/verification.json` records the output metadata; `out/contact-sheet.png` summarizes all scenes. Optional QA scripts use the repository's Playwright installation in `tests/e2e`.

The venue's real WhatsApp contact was configured separately in the local application at the user's request. Its generated link was checked without sending a message. The full number is not included in the composition or exported video.
